# Chandan — Premium Portfolio Website

A responsive portfolio website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — main portfolio with phone number and contact links
- `style.css` — responsive theme, layout and animations
- `script.js` — dark/light theme switch, mobile navigation, project filters, reveal effects and contact email setup
- `resume.html` — resume viewer page with inline PDF preview and download links
- `Chandan_Resume.pdf` — your uploaded resume, included as supplied
- `Chandan.jpg` — your profile photo

## Run locally
Keep the folder structure unchanged and open `index.html` in a modern browser. The contact form opens the visitor's email app; it does not submit to a server.

## Resume
Open `resume.html` to view or download the actual PDF. The homepage also has a direct Download Resume button.

## Publish using GitHub Pages
1. Create a GitHub repository for the website.
2. Upload all files and the `assets` folder (including `Chandan_Resume.pdf`).
3. Open **Settings → Pages** and choose the branch/folder you want to publish.
4. Wait for GitHub Pages to publish and then open the provided URL.
